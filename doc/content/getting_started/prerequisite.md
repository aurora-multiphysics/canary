# Prerequisites

- MOOSE-MFEM installed and built ready to use.

  - see official installation guides [here](https://mooseframework.inl.gov/getting_started/installation/install_mfem.html)
  - Or use a prebuilt module on a HPC system like Cumulus.

- Base knowledge of the finite element method.

  - A good place to start if this is new to you is the
    [MOOSE Workshop Intro to FEM](https://www.youtube.com/watch?v=QPuK6OdF2hM&t=4256s).

- Paraview installed.
